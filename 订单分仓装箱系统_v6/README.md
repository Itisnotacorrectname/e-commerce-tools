# 订单分仓装箱系统

## 快速启动

**Windows：** 双击 `启动系统.bat`
**Mac/Linux：** 终端运行 `bash 启动系统.sh`

浏览器会自动打开 http://localhost:5050

---

## 使用流程

1. 点击页面右上角 **「下载输入模板」** 获取 Excel 模板
2. 按模板填写以下4个 Sheet：
   - **SKU信息**：SKU编号 + 单件体积(m³)
   - **订单数量**：本次工厂订单各SKU数量
   - **目标比例**：每个SKU在每个仓库的目标库存比例（每SKU所有仓库之和=1）
   - **库存在途**：各仓库当前在库数量、在途数量、预计到货日期
3. 上传填好的文件，点击 **「开始运算」**
4. 运算完成后点击 **「下载报告」** 获取结果 Excel

---

## 输出报告说明

报告含4个 Sheet：
- **📊汇总**：集装箱总数、平均利用率、各仓库分布
- **分仓明细**：每个SKU在每个仓库的分配数量及比例对比
- **装箱清单**：每个集装箱的目标仓库、装载SKU、利用率
- **⚠️警告**：分仓比例异常、跨仓转移、低利用率箱等提示

---

## 存档机制

每次运算后自动存档于 `archives/` 目录，按时间戳命名：

```
archives/
  20260421_143022/
    输入数据_20260421_143022.xlsx   ← 输入存档
    输出报告_20260421_143022.xlsx   ← 输出报告
    meta.json                        ← 批次元数据
  20260421_160510/
    ...
```

在页面左侧历史面板可查看、重新下载或删除任意历史批次。

## 核心约束参数（修改 allocator.py）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `CONTAINER_CAPACITY` | 66.0 m³ | 集装箱最大容积 |
| `MIN_UTILIZATION` | 0.98 | 最低利用率（98%）|
| `MAX_SKUS_PER_CONTAINER` | 18 | 每箱最多SKU种数 |
